지방계약 길라잡이(가칭) (안)

예시:

추가 확인

상세 옵션(자동 인식 값 수정)
계약금액·기간은 통합서약서(5·6·10·11번) 판정에 씀. 비우면 예상금액으로 자동 계산
1인 수의계약 업체별 한도 확인(선택)
업체명·사업자번호는 받지 않음. 숫자만 입력하며 저장하지 않음(집행기준 제5장 제3절 2-다)
500만원 미만 건 제외
500만원 미만 건 포함
위에 사업명과 예상금액을 입력하거나 예시를 누르면 판정 결과가 여기에 나타남

용어 도움말

추정가격
예정가격 결정 전에 산정한 가격으로, 부가세와 관급자재 가격을 제외함. 계약 방법 판단 기준(시행령 제2조 제1호, 제7조)
추정금액
추정가격 + 부가세 + 관급자재 등. 시행령 제2조에는 정의가 없음 [확인 필요: 다른 규정의 정의]
관급자재
입력란을 따로 두어 추정가격에서 뺌(시행령 제7조 본문)
예산액
확보된 예산. 추정금액과 같다고 가정하지 않음 → "부가세 포함"을 선택하면 ÷1.1로만 환산
계약금액
업체와 실제 체결하는 금액(부가세 포함). 통합서약서 계약보증금·하자보수보증금 등 판정 기준
판정 원칙
계약 방법·한도·서류 판정은 100% 규칙 데이터로 결정함(같은 입력 → 같은 결과). 기준금액은 "이하" 기준이므로 정확히 같으면 가능으로 판정

최신 개정 여부는 국가법령정보센터(law.go.kr)와 행정안전부 예규에서 확인 바람
